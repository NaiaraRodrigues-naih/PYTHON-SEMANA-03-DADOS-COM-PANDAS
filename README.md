## Projetos

### Projeto 1 — Introdução ao Pandas `01_introducao_pandas.py`
Primeiros passos com a biblioteca Pandas: Series, DataFrames, leitura de dados e operações básicas.

### Projeto 2 — Limpeza de Dados `02_limpeza_dados.py`
Como tratar dados sujos: valores nulos, duplicatas, tipos incorretos e padronização.

### Projeto 3 — Análise Exploratória `03_analise_exploratoria.py`
Estatísticas descritivas, agrupamentos, filtros e insights a partir de dados reais.

### Projeto 4 — Visualização e Gráficos `04_visualizacao_graficos.py`
Criação de gráficos com Matplotlib e Seaborn: barras, linhas, pizza e histogramas.

### Projeto 5 — Projeto Final `05_projeto_final.py`
Análise completa de um dataset real: limpeza, análise e visualização em um único script.
